Experiment 4: User Activity and File Manipulation Using Shell Scripts

Objective:
To implement shell scripts for monitoring user activity and manipulating file contents.

Tasks Performed:

    Developed a script to determine how long a specified user has been logged into the system.
    Created a script to display lines between specified starting and ending line numbers.
    Implemented a script to delete all lines containing a specified word from one or more input files.

Outcome:
Understood user session monitoring, positional parameters, loops, text processing, and file manipulation using shell scripting.
